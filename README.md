# 🌑 Moondancer

Moondancer is a 2D platformer game developed with the Godot Engine. Guide your character through mystical forests, ancient temples, and magical landscapes, harnessing the powers of the elements to overcome obstacles and enemies.

## Features

- Hand-drawn backgrounds and character sprites
- Elemental abilities: Fire, Water, Air, and Plant
- Challenging platforming and puzzle elements
- Atmospheric soundtrack and sound effects
- Multiple levels and unique environments
- Pause and tutorial menus

## Installation

1. **Install [Godot Engine](https://godotengine.org/)** (version 3.x or 4.x recommended).
2. Clone or download this repository:

   ```bash
   git clone https://github.com/Jose26398/moondancer-godot.git
   ```

3. Open the `Moondancer` folder in Godot.
4. Run the project from the Godot editor.

## Controls

- **Arrow Keys / WASD**: Move and elemental powers
- **Esc**: Pause menu

## Folder Structure

- `Assets/` - Art assets (backgrounds, characters, UI)
- `Character/` - Player and enemy scripts and scenes
- `Level/` - Level scenes, tilesets, and activable objects
- `Sounds/` - Music and sound effects
- `UserInterface/` - Menus and UI scripts
